# 如何维护（接口原理 + 失效时的排查步骤）

这个工具不依赖任何第三方解析站，直接走抖音官方 Web 接口。好处是稳定、无水印、无需登录；
代价是**官方接口偶尔会变**，变了就要按下面的表改几行。全文都是实操过的真实链路。

## 一、完整链路

```
① 用户粘贴的分享文本/短链
   v.douyin.com/XXXXXX/   → 302 →  www.iesdouyin.com/share/(video|note)/<aweme_id>/?...
   解析方式：跟随重定向，取最终 URL 里的 /(video|note)/(\d{6,})

② 游客态 ttwid（不需要登录、不需要 cookie）
   POST https://ttwid.bytedance.com/ttwid/union/register/
   body: {"region":"cn","aid":1768,"needFid":false,"service":"www.ixigua.com",
          "migrate_info":{"ticket":"","source":"node"},"cbUrlProtocol":"https","union":true}
   → 响应头 Set-Cookie: ttwid=...;   缓存到 ~/.cache/douyin-nomark/ttwid

③ 作品详情（必须带 UA + Referer + ttwid，否则 403 或空）
   GET https://www.douyin.com/aweme/v1/web/aweme/detail/
       ?aweme_id=<id>&device_platform=webapp&aid=6383&channel=channel_pc_web
   headers:
       User-Agent: <桌面 Chrome UA>
       Referer:    https://www.douyin.com/(video|note)/<id>
       Cookie:     ttwid=<上一步的值>

④ 取无水印地址
   视频：aweme_detail.video.play_addr.url_list
        aweme_detail.video.play_addr_h264.url_list
        aweme_detail.video.play_addr_265.url_list
        aweme_detail.video.bit_rate[*].play_addr.url_list
   图文：aweme_detail.images[*].url_list
   （判断：URL 里含 watermark=1 或 logo_name= 就是带水印，别用）
```

## 二、字段对照表

| 想要的东西 | 取哪里 | 有无水印 |
|:---|:---|:---|
| 视频（推荐） | `video.play_addr.url_list` | ✅ 无水印 |
| 视频（H264/HEVC 备用） | `video.play_addr_h264` / `play_addr_265` | ✅ 无水印 |
| 视频（多码率） | `video.bit_rate[*].play_addr.url_list` | ✅ 无水印 |
| 视频（**别用**） | `video.download_addr.url_list` | ❌ 带 `logo_name=` |
| 图文（推荐） | `images[*].url_list`（`tplv-dy-aweme-images`） | ✅ 无水印 |
| 图文（**别用**） | `images[*].download_url_list`（`tplv-dy-water`） | ❌ 带水印 |
| 封面 | `video.cover.url_list` | — |
| 标题 | `desc` | — |
| 作者 | `author.nickname` / `author.unique_id` | — |
| 发布时间 | `create_time`（unix 秒） | — |

## 三、失效时的排查顺序

| 症状 | 可能原因 | 处理 |
|:---|:---|:---|
| `拿不到作品数据（接口返回空）` | ttwid 过期 | 删 `~/.cache/douyin-nomark` 重试；代码里已自动重取一次 |
| 返回 `{"status_code": 8}` 之类 | 被风控 / 需要签名 | 加真实浏览器 UA、加 `msToken`，或改用移动端接口 `api-hl.amemv.com`；详见第四节 |
| 详情接口 403 / `blocked` | 该接口已加签名校验（`a_bogus`） | 见第四节 |
| 视频直链 403 / 只有几 KB | CDN 签名过期（URL 里 `x-expires`） | 重新调一次详情接口拿新直链即可（别缓存直链） |
| 图文某几张失败 | 部分 CDN 节点抖动 | 代码会依次试 `url_list` 里的多个镜像 |
| 拿到的地址里有 `watermark=1` | 取错字段了 | 检查是不是用了 `download_addr` |

## 四、如果哪天接口加了签名（a_bogus / X-Bogus）

抖音 Web 接口历史上多次加过签名参数。出现「接口 200 但返回空」且 ttwid 是新的，基本就是这个原因。三条路：

1. **换移动端接口**（历史上比 Web 接口宽松）：
   ```
   https://api-hl.amemv.com/aweme/v1/aweme/detail/?aweme_id=<id>   (iPhone UA)
   ```
2. **补 `msToken`**：先从 `https://www.douyin.com/` 的响应头或页面 JS 里拿 `msToken`，再拼进查询串。
3. **本地算签名**：把页面里的签名函数抽出成本地实现（社区有 JS/Python 实现），算 `a_bogus` 后拼进 query。
   —— 这条路维护成本最高，但最耐改。

改完记得：`dnmark --doctor` 自检 + 用一条已知作品验证，然后更新 `CHANGELOG.md`。

## 五、开发自测清单（改完代码必跑）

```bash
python3 scripts/dnmark.py -v                 # 版本
python3 scripts/dnmark.py --doctor           # 网络 / ttwid / 接口
python3 scripts/dnmark.py -o /tmp/t "<视频链接>"   # 视频：应输出 mp4 + 分辨率
python3 scripts/dnmark.py -o /tmp/t "<图文链接>"   # 图文：应输出 目录 + zip + 拼图
python3 scripts/dnmark.py --json -o /tmp/t "<链接>" | python3 -m json.tool
```

**验证无水印的小技巧**：抽帧后 OCR，水印文字会被识别出来。

```bash
ffmpeg -v error -i out.mp4 -vf fps=1/3 /tmp/f/_%02d.png
for f in /tmp/f/*.png; do tesseract "$f" - -l chi_sim+eng --psm 6; done
# 全部为空 = 没有水印文字
```
